Voidswarm LAN {{VERSION}}

Host a Voidswarm game for your class or your home on this PC. Players join from their browsers on the same network. Nothing is installed, and the game needs no internet.

1 Unblock the zip (once, before extracting)

Right-click the downloaded voidswarm-lan-{{VERSION}}-win-x64.zip → Properties → tick Unblock → OK. This stops Windows from asking about every file.

2 Extract it into your user folder

Right-click the zip → Extract All…, type %USERPROFILE% in the box, and extract. You get C:\Users\<you>\Voidswarm LAN.

Don't extract toWhy
the Desktop or Documentsthey often sync to OneDrive, which would copy the chat log and passwords to the cloud
Downloads, Temp, a USB stickantivirus suspicion, automatic clean-up, or no file permissions
directly under C:\every user of the PC could change the files

Voidswarm refuses to start from those places and tells you where to move it.

3 Double-click Start Voidswarm Host.cmd

A small black window opens. Keep it running: closing it stops the game. After the first run it opens minimised. Don't click inside it (a selection pauses its text; the game keeps running).

If Windows shows "Windows protected your PC", the zip wasn't unblocked. Click More info → Run anyway, or go back to step 1.

4 The first run: create the host admin login

Your browser opens the Host Control Panel at http://localhost:7778 (the black window shows the address if it doesn't). The setup code is already filled in; it is also in the black window.

  1. Choose a username and a password (10 characters or more) for the host admin. Write the password down somewhere safe.
  2. Choose Home or School, and name the server.
  3. In School mode, choose how students get accounts: school email (a 6-digit code is emailed) or a class roster (printed login slips, no email needed).
  4. Make the recovery file when the panel offers it, and keep it and its passphrase apart, away from this PC.

5 Let other devices in: the firewall

The first time, Windows may ask about "Node.js JavaScript Runtime". That is Voidswarm's engine (runtime\node.exe). Tick Private networks and click Allow.

  • Your network must be set to Private in Windows (Settings → Network & internet → your connection → Network profile type). On a Public network only this PC can play.
  • Bitdefender: allow runtime\node.exe under Protection → Firewall → Rules (Home/Office networks). If Bitdefender ever flags it, add an exception under Protection → Advanced Threat Defense.
  • If runtime\node.exe disappeared (the black window says your antivirus may have removed it): open Bitdefender → Protection → Quarantine, restore the file, and add an exception for it.
  • Router guest networks and "AP isolation" stop players from reaching this PC. Use the main Wi-Fi, and plug this PC in with a cable if you can.
  • No administrator rights (a school PC)? The Windows prompt then asks for an administrator's password, so other devices can't connect yet. Ask IT to run Allow Voidswarm (for IT).cmd once (it is in this folder; FOR SCHOOL IT.txt explains it). Until then you can still play and use the control panel on this PC. The control panel warns you while other devices probably can't connect.

6 Players join

The control panel's Home tab shows the join address, for example http://192.168.1.50:7777. Players type it into their browser on the same Wi-Fi. Show on projector opens a page with only the join address and the rooms, safe to show the class.

Before class, open the address followed by /check on one student device to test it.

7 Everyday use

To…Do this
stop the gamepress Ctrl+C in the black window, or Stop in the control panel. The chat log is saved first.
open the control panel againdouble-click Start Voidswarm Host.cmd while it runs: it opens the panel.
update Voidswarmstop the host, put the new voidswarm-lan-…-win-x64.zip in this folder (or in an updates folder inside it), and double-click Update Voidswarm.cmd. Your data, the firewall permission and your shortcuts stay as they are. A backup is made first, and the old version is kept.
go back to the old versionrun Update Voidswarm.cmd --rollback from a Command Prompt in this folder (host stopped).
reset a forgotten admin passworddouble-click Reset admin password.cmd on this PC. It prints a new setup code; then open the control panel and set a new password.
restore a backupstop the host and double-click Restore a backup.cmd, or use Server → Backups in the control panel.
let other devices in without admin rightsgive IT Allow Voidswarm (for IT).cmd (in this folder) and FOR SCHOOL IT.txt: IT runs it once as administrator.
stop the folder-permission warningclick Don't warn me again on it in the control panel (or extract Voidswarm into your user folder, %USERPROFILE%).

a message about the folder (OneDrive, Downloads, …)Move the whole Voidswarm LAN folder to %USERPROFILE% and start it there.

Keep this PC's Windows password and BitLocker on: the chat log and the student accounts live in the data folder. Backups in data\backups are encrypted; copies you keep elsewhere belong on storage your school approves, not a personal cloud drive.
